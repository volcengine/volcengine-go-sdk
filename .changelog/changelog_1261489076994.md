## CORE

- 新增 `volcengineerr.PrintError`、`volcengineerr.GetErrorDetails` 和 `volcengineerr.DetailedRequestFailure`（`ResponseDetails()`），可直接输出或读取错误的 HTTP 状态码、请求 ID、响应头、响应正文快照和底层原因。
- 重试判断支持识别 `%w` 包装的错误，限流、凭证过期和自定义错误码仍会触发重试；`ReadError`、`SerializationError` 只在底层原因可重试时重试。
- HTTP 200 下响应读取、解码或结果转换失败时，改为返回 `RequestFailure`（错误码为 `ReadError` 或 `SerializationError`）并保留原始正文；请求 ID 可从响应头兜底获取。
- AssumeRole、OIDC、SAML 凭证请求统一返回 `volcengineerr.RequestFailure`，错误文本改为 SDK 默认格式 `Code: Message`；AssumeRole 和 `StsProvider` 未设置 `Schema` 时默认使用 HTTPS。
